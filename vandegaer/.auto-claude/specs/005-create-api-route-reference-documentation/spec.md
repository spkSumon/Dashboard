# Create API Route Reference Documentation

## Overview

The Router class supports dynamic route registration but there's no documentation of available API endpoints. The public/index2.php file likely defines routes but developers must read the source to discover available endpoints, HTTP methods, and required parameters.

## Rationale

API route documentation is fundamental for frontend developers, API consumers, and testers. Without it, discovering available functionality requires code archaeology. As SocialBit grows to support multiple platforms (Instagram, TikTok, Facebook), having a clear API reference becomes essential.
