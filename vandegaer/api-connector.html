📱 TikTok API v2
💡 OAuth Flow Instructions:
1. Click "Start OAuth Flow" to authorize TikTok
2. Login to TikTok and grant permissions
3. You'll be redirected back automatically
4. Click "Check Status" to verify connection
5. Use "Sync Posts" to fetch your TikTok content

ℹ️ OAuth scopes: user.info.basic, user.info.profile, user.info.stats, video.list
ℹ️ Redirect URI: https://socialbit.g-bit.be/public/api/tiktok/callback
📸 Instagram Graph API
💡 Setup Hints:
1. Go to Meta Developers
2. Create app, add Instagram Basic Display
3. Get access token using Graph API Explorer
4. Exchange for long-lived token (60 days)
