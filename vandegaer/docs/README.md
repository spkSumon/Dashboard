## 🗂️ File Organization Rules

### Keep in Root
- Active implementation guides
- Current strategy documents
- Migration logs (recent)
- Troubleshooting guides (active issues)

### Move to `/archive/`
- Completed plans (more than 1 month old)
- Superseded strategies
- Deprecated documentation
- Historical analysis

### Move to `/reports/`
- Audit reports
- Technical assessments
- Quality reviews
- Performance analysis

### Move to `/screenshots/`
- UI screenshots
- Demo visuals
- Testing screenshots
- Design mockups
