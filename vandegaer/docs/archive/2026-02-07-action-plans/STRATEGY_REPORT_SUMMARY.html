Pipeline Engineer

🏗️ 5-Layer Pipeline Architectuur

  • Layer 1: Data Sources (APIs, CSV, webhooks, manual)
  • Layer 2: Ingestion (collectors met validatie)
  • Layer 3: Queue (MySQL-based job management)
  • Layer 4: Conflict Resolution (smart merge algoritme)
  • Layer 5: Storage (posts, metrics_history, data_lineage)

⚙️ Conflict Resolution Strategie

  • Priority Hierarchy: API > Third-party API > CSV > Manual
  • Timestamp-based Last Write Wins binnen zelfde tier
  • Validatie regels: Detecteert spikes (>10×) en drops (>10%)
  • Full audit trail in nieuwe data_lineage table
  • Principe: Geen data verlies - alles wordt gelogd

🔧 Technology Recommendations

  • Queue: MySQL-based (Phase 1), migreer naar Redis bij >10K jobs/dag
  • Scheduler: Plesk cron jobs (4 AM batch per tenant)
  • Rate Limiting: Symfony Rate Limiter component (vanilla, no framework)
  • Libraries: Composer-based dependencies

Data Scientist

📊 Engagement Quality Score (EQS) - NIEUWE PRIMARY METRIC

  • Weighted formula: (likes×1 + comments×3 + shares×5 + saves×4) / views × 100
  • Waarom? Shares en saves = HIGH intent, passive likes niet
  • EQS < 2%: Content niet resonerend
  • EQS 5-10%: Goede performance
  • EQS > 10%: Excellent, repliceer dit!

🎯 Analytics Strategie

  • Watch Time & Completion Rate - Algorithm priority #1
  • Historical Comparison - Month-over-month met LAG() window functions
  • Benchmark Comparison - "Je doet het 2× beter dan gemiddeld"
  • Confidence Indicators - Sample size warnings (n<10 = low)
  • Anomaly Detection - Viral alerts (IQR method) + performance drops (Z-score)

🔮 Predictive Analytics (Rule-Based)

  • Content Performance Prediction: Score 0-12 points VOOR posting
  • Factoren: Optimal time (+2), proven hashtags (+5), best format (+2), etc.
  • Trend Forecasting: Moving averages + linear extrapolation
  • Smart: Vermijd ML complexity voor MVP (implementeer later bij 1000+ posts)

💡 Plain Language Presentatie

  • "Je bent 2× beter dan gemiddeld" niet "212% of median"
  • "68% kijkt tot het einde" niet "completion_rate: 0.68"
  • Viral Alert: "🚀 Post #1247: 18.3% engagement (4× je gemiddelde)"
  • Performance Drop: "⚠️ Laatste 3 posts underperformden"
